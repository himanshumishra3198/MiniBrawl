# Third-party assets

Everything in the game is either drawn for it or **CC0 (public domain)**. CC0
imposes no obligation to credit, so nothing here is a licence condition — the
file exists so the origin of each asset stays known, and so a future contributor
can tell at a glance what may be redistributed.

## Drawn for this project

| Asset | Generated by |
|---|---|
| `Art/Characters` — six Para SF commandos, five poses each | `tools/commando.py` |
| `Art/Weapons` — one firing arm and rifle per seat | `tools/commando.py` |

Side view, not front: a front-facing character cannot hold a rifle convincingly,
which is what made an earlier attempt using Kenney's astronaut look wrong the
moment a weapon was attached to it. The weapon is not a prop laid over the body —
the firing arm and rifle are one sprite pivoting at the shoulder, which is how a
2D shooter keeps the muzzle attached through a full circle of aim.

The uniform takes the seat colour from `PlayerColors` and the kit stays neutral,
so the largest coloured area on screen is the one that says which player this is.
Six of these have to be told apart while moving, on a phone.
